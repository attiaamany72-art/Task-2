1. Introduction

Cascading Style Sheets (CSS) is a stylesheet language used to describe how HTML documents are displayed. CSS controls the appearance of web pages, including colors, fonts, spacing, borders, and page layout. It helps make websites attractive, organized, and easier to use.

2. Main Topic: What is CSS?

Importance of CSS

CSS separates the content of a web page from its design. HTML provides the structure of the page, while CSS controls its visual presentation. Using CSS also makes it easier to apply a consistent design to many pages on the same website.

Types of CSS

  • Inline CSS: Written inside an HTML element using the style attribute.
  • Internal CSS: Written inside a style element in the HTML head.
  • External CSS: Written in a separate .css file and connected to the HTML page.

Example of CSS

The following example changes the color of a heading and makes the text larger: 

h1 {
    color: blue;
    font-size: 30px;
}

Comparison Between HTML and CSS

Builds the structure of a web page. Controls the design and appearance of a web page.
Uses elements such as headings and paragraphs. Uses rules and properties such as color and font-size.
Defines the content. Defines how the content looks.

3. Conclusion

CSS is an essential technology in web development. It works with HTML to create clear, attractive, and well-organized websites. Learning CSS is an important step for anyone who wants to design web pages.
